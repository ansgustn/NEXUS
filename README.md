# NEXUS 체험존: AI 기반 역사 인물 인터랙티브 시스템

> 교내 NEXUS 체험존 오프라인 전시를 위해 개발된 AI 융합 서비스로, 사용자가 역사적 인물과 대화하고 직접 맞춤형 영상을 제작하여 소장할 수 있는 인터랙티브 플랫폼입니다.

## 1. 프로젝트 개요 (Overview)
과거의 역사 인물(세종대왕, 백범 김구, 유관순 열사, 이순신 장군, 신사임당)을 현대의 AI 기술로 재현하여 생동감 있는 역사 체험을 제공합니다. LLM을 활용한 자연스러운 질의응답 처리와 시각적인 립싱크(Lip-sync) 애니메이션을 결합하여, 사용자가 직접 텍스트를 입력하고 영상을 다운로드할 수 있는 사용자 참여형 엔터테인먼트 시스템을 구축했습니다.

## 2. 기술 스택 (Tech Stack)
* **Frontend:** React
* **Backend:** Java (Antigravity)
* **AI & API:** Gemini API (LLM 기반 대사 생성), D-ID API (안면 애니메이션 및 영상 생성)
* **Media Processing:** FFmpeg

## 3. 핵심 기능 (Key Features)

* **LLM 기반 실시간 질의응답 및 동기화 영상 재생 (체험 페이지)**
  * 사용자가 특정 역사 인물을 선택하고 질문을 던지면, Gemini API가 인물의 맥락과 성격에 맞는 대사를 실시간으로 생성합니다.
  * 생성된 텍스트는 D-ID API를 거쳐 인물의 눈 깜빡임과 입모양이 대사에 완벽히 동기화된 영상으로 렌더링되어 재생됩니다.
* **사용자 맞춤형 대사 기반 영상 제작 및 소장 (스튜디오 페이지)**
  * 사용자가 원하는 대사를 직접 입력하면 해당 인물이 그 대사를 읽어주는 커스텀 영상을 생성합니다.
  * 대사 수정 및 영상 재렌더링(Regenerate) 기능을 제공하며, 완성된 영상은 로컬로 다운로드하여 체험존의 기념품으로 소장할 수 있습니다.

## 4. 기술적 문제 해결 (Troubleshooting)

**문제 1: 오픈소스 비전 모델의 안면 애니메이션 퀄리티 한계**
* **상황:** 초기 개발 시 SadTalker, LivePortrait 등의 오픈소스를 활용하여 정지 이미지에 립싱크를 구현하려 했으나, 입술 주변에 노이즈가 심하게 끼고 타원형의 흑백 잔상이 남는 등 전시용으로 부적합한 품질 문제가 발생했습니다.
* **해결:** 오프라인 전시 체험존의 특성상 시각적 퀄리티가 최우선이라고 판단하여, SOTA급 상용 솔루션인 D-ID API로 파이프라인을 전환했습니다. 무료 버전의 워터마크를 FFmpeg 기반 페이드 아웃으로 가리려는 시도 중 픽셀 깨짐 현상이 발생하자, 렌더링 안정성을 위해 최종적으로 Pro 플랜을 도입하는 기술적 의사결정을 통해 고품질의 미디어 경험을 확보했습니다.

**[초기 테스트 영상: 무료 SOTA 모델을 활용한 립싱크(Lip-sync) 생성의 한계]**

초기 기획 단계에서 무료 SOTA(State-of-the-Art) 모델을 활용하여 백범 김구 선생님의 안면 애니메이션을 구현한 테스트 영상입니다. 

음성에 맞춰 입이 움직이도록 처리는 되었으나, 렌더링 퀄리티와 움직임에서 심각한 시각적 이질감이 발생했습니다. 원본 이미지의 입술 윤곽은 그대로 고정된 상태에서 내부만 억지로 움직이려다 보니 안면 전체가 일그러지는 현상이 나타났습니다. 또한, 구강 내부가 단순한 검은색 타원형에 흰색 픽셀로 치아를 조잡하게 덧칠한 수준으로 표현되었습니다. 

이 테스트 결과를 통해 해당 모델이 요구하는 수준의 자연스러운 표정 연기를 수행하기 어렵다고 분석하였고, 결과적으로 더 정교한 안면 매핑 기술을 제공하는 상용 솔루션(D-ID)으로 파이프라인을 전면 수정하는 계기가 되었습니다.

**[초기 테스트 영상: FFmpeg를 활용한 워터마크 블러(Blur) 처리의 한계]**

D-ID 무료 API로 생성한 백범 김구 선생님의 초기 테스트 영상입니다. 안면 애니메이션과 립싱크 자체는 자연스럽게 구현되었으나, 화면 전체에 빗줄기처럼 깔린 사선 워터마크가 문제였습니다. 

이를 소프트웨어적으로 해결하기 위해 FFmpeg로 워터마크 영역 블러 처리를 시도한 결과물입니다. 영상에서 볼 수 있듯 필터 적용 과정에서 전체 프레임의 픽셀이 심하게 뭉개지고 형태를 알아볼 수 없을 정도로 화질이 훼손되었습니다. 이 테스트를 통해 영상 후처리의 기술적 한계를 명확히 확인하고, 전시 퀄리티 보장을 위해 최종적으로 Pro 플랜을 도입하게 되었습니다.

**문제 2: 역사 인물의 음성 데이터(Voice Data) 부재 및 합성의 어려움**
* **상황:** 세종대왕, 이순신 장군 등 실제 녹음된 음성 데이터가 존재하지 않는 인물의 목소리를 구현해야 하는 데이터 수집의 한계에 직면했습니다.
* **해결:** 미디어 레퍼런스 방식을 채택했습니다. 해당 역사 인물을 연기한 사극 드라마, 영화 배우의 목소리나 관련 유튜브 영상에서 고품질 오디오 샘플을 추출하여 보이스 레퍼런스로 활용함으로써, 각 인물의 이미지에 걸맞은 무게감 있고 자연스러운 목소리 톤을 합성해 냈습니다.
