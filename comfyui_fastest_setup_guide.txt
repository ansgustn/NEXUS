 1. 분산 네트워크 연동 구조 (노트북 <── LAN / WiFi ──> 데스크탑 RTX 16GB)
--------------------------------------------------------------------------------

노트북과 데스크탑 사이에 복잡한 공유 폴더(Samba)나 파일 복사가 전혀 필요 없습니다!
ComfyUI의 자체 REST API(HTTP)를 통해 모든 파일과 명령이 자동 전송됩니다.

  [현재 노트북]                                     [옆 컴퓨터 (RTX 16GB)]
 ┌─────────────────────────┐                       ┌─────────────────────────┐
 │ 1단계: 인물 선택        │                       │ ComfyUI 서버             │
 │         │               │                       │ (--listen 0.0.0.0:8188) │
 │ 2단계: 음성 생성 (0.3초)│                       │                         │
 │   (Edge-TTS MP3 생성)   │                       │                         │
 │         │               │                       │                         │
 │ 3단계: 영상 생성 요청 ───┼─ (1) HTTP 이미지/음성 ─►│ • Wav2Lip GPU 인퍼런스  │
 │   (POST /api/video)     │      업로드 전송      │   (RTX 16GB: 2~4초)     │
 │                         │                       │                         │
 │                         │◄─ (2) HTTP 완성 MP4 ──┼─ • MP4 비디오 인코딩     │

 │                         │                       │                         │
 │ 4단계: 비디오 재생      │                       │                         │

 2. 옆 컴퓨터(데스크탑 RTX 16GB) 준비 및 ComfyUI 실행 방법
--------------------------------------------------------------------------------

1) 데스크탑 IP 확인
   - 데스크탑에서 CMD(명령 프롬프트) 실행 후: `ipconfig` 입력
   - `IPv4 주소` 확인 (예: `192.168.0.25` 또는 `20.30.212.143`)

2) ComfyUI 외부 접속 허용 실행 (필수 옵션: --listen 0.0.0.0)
   - 기본 실행 시 `127.0.0.1`로만 열려 노트북에서 접속이 안 됩니다.
   - 반드시 `--listen 0.0.0.0` 플래그를 붙여 실행해야 합니다:

   [데스크탑 실행 명령어]
   python_embeded\python.exe ComfyUI\main.py --windows-standalone-build --fast fp16_accumulation --listen 0.0.0.0 --port 8188

   * 팁: run_nvidia_gpu.bat 파일을 편집하여 인자 뒤에 `--listen 0.0.0.0`을 추가하면 편합니다.

3) 노트북의 `.env` 파일에 데스크탑 IP 지정
   - 파일 위치: `c:\Users\user\Desktop\NEXUS\.env`
   - 내용:
     COMFYUI_URL=http://<데스크탑_IPv4_주소>:8188
     (예시: COMFYUI_URL=http://192.168.0.25:8188)


--------------------------------------------------------------------------------
 3. 데스크탑에 설치해야 할 커스텀 노드 및 가중치 모델
--------------------------------------------------------------------------------

데스크탑의 `ComfyUI/custom_nodes` 폴더에 아래 2개 라이브러리가 있으면 됩니다:

1) 필수 커스텀 노드 (Custom Nodes)
   ① ComfyUI_wav2lip
      - git clone 또는 폴더 복사: custom_nodes/ComfyUI_wav2lip
   ② comfyui-videohelpersuite (VHS)
      - ComfyUI-Manager에서 "Video Helper Suite" 검색 설치
      - 또는 git clone: custom_nodes/comfyui-videohelpersuite
   ③ comfyui-edgetts (자연스러운 한국어 인물 음성 합성)
      - ComfyUI-Manager에서 "EdgeTTS" 검색 설치
      - 또는 git clone: custom_nodes/comfyui-edgetts

2) 필수 가중치 모델 파일
   ① wav2lip_gan.pth (415.6 MB)
      - 다운로드 경로: custom_nodes/ComfyUI_wav2lip/Wav2Lip/checkpoints/wav2lip_gan.pth
   ② s3fd.pth (얼굴 탐지 모델, 85.7 MB)
      - 다운로드 경로: custom_nodes/ComfyUI_wav2lip/Wav2Lip/face_detection/detection/sfd/s3fd.pth

 4. ComfyUI 최단 시간 노드 배치도 (EdgeTTS 내장 초고속 4개 노드 직렬 구성)
--------------------------------------------------------------------------------

★ 번거로운 외부 음성 파일 업로드 없이, 대사 텍스트만 넣으면
  ComfyUI 내부에서 EdgeTTS로 음성 생성과 립싱크를 2~4초 만에 원스톱 처리합니다.

┌─────────────────────────────────────────────────────────────────────────────┐
│ [Node 1: LoadImage]                                                         │
│  - image: "kim-koo.webp" (인물 이미지 선택)                                  │
│  - 출력: IMAGE ────────────────────────────┐                                │
└─────────────────────────────────────────────┼───────────────────────────────┘
                                              │
┌─────────────────────────────────────────────┼───────────────────────────────┐
│ [Node 2: EdgeTTS] (🔊 원클릭 고품질 음성 합성) │                               │
│  - 입력 핀/파라미터:                        │                               │
│     * text: 대사 문장 입력                 │                               │
│     * voice: "[Korean] ko-KR InJoon" (인물별 성우 자동 적용)                 │
│     * speed: 0.90 / pitch: -15 (인물별 톤/피치)                             │
│  - 출력: AUDIO ───────────────────────────┐ │                               │
└───────────────────────────────────────────┼─┼───────────────────────────────┘
                                            │ │
                                            ▼ ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ [Node 3: Wav2Lip] (초고속 PyTorch CUDA 립싱크)                              │
│  - 입력 핀:                                                                 │
│     * images ◄─── [Node 1: LoadImage]의 IMAGE 핀                            │
│     * audio  ◄─── [Node 2: EdgeTTS]의 AUDIO 핀                              │
│  - 파라미터:                                                                │
│     * mode: "repetitive" (단일 이미지를 오디오 길이에 맞춰 반복 공급)         │
│     * face_detect_batch: 16 (16GB VRAM 배치 크기 최적화)                     │
│  - 출력 핀:                                                                 │
│     * images ────────────────────────────┐                                  │
│     * audio  ──────────────────────────┐ │                                  │
└────────────────────────────────────────┼─┼──────────────────────────────────┘
                                         │ │
                                         ▼ ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ [Node 4: VHS_VideoCombine] (MP4 동영상 인코딩 및 저장)                       │
│  - 입력 핀:                                                                 │
│     * images ◄─── [Node 3: Wav2Lip]의 images 핀                             │
│     * audio  ◄─── [Node 3: Wav2Lip]의 audio 핀                              │
│  - 파라미터 (★ 중요: 경고 제거 및 입술 싱크 밀림 완전 방지):               │
│     * frame_rate: 25.0                                                      │
│     * format: "video/h264-mp4"                                              │
│     * pix_fmt: "yuv420p" (표준 H.264 브라우저 호환 색역, 경고 제거)          │
│     * crf: 19 (고화질 무손실급 비디오 인코딩)                               │
│     * trim_to_audio: true (★ 핵심: 오디오 끝나는 순간 영상 프레임 칼차단!) │
│     * save_output: true                                                     │
│     * filename_prefix: "nexus_avatar"                                       │
│  - 결과: 음성 종료와 동시에 입이 정확하게 닫히는 완벽한 동기화 비디오 출력    │
└─────────────────────────────────────────────────────────────────────────────┘

 5. 독립 분리 3단계 파이프라인 (API 사용법)
--------------------------------------------------------------------------------

음성 생성과 영상 생성을 분리하여 아래 순서대로 호출합니다:

[1단계: 인물 선택]
  - 프론트엔드에서 인물 선택 (kim-koo, king-sejong, yi-sun-sin 등)

[2단계: 음성 생성 (초고속 0.3초)]
  - 호출: POST http://localhost:3001/api/audio/generate
  - 요청 Body:
    {
      "figureId": "kim-koo",
      "text": "나는 우리나라가 세계에서 가장 아름다운 나라가 되기를 바란다."
    }
  - 응답 (즉시 0.3초 반환):
    {
      "success": true,
      "figureId": "kim-koo",
      "speechText": "나는 우리나라가 세계에서 가장...",
      "audioUrl": "/audio/guide_speech_1789114090821.mp3"
    }
  - 장점: 이 시점에 브라우저 오디오 플레이어로 목소리와 대사를 즉시 먼저 들려줄 수 있음!

[3단계: 영상 생성 (원격 데스크탑 ComfyUI 호출 2~4초)]
  - 호출: POST http://localhost:3001/api/video/generate
  - 요청 Body:
    {
      "figureId": "kim-koo",
      "audioUrl": "/audio/guide_speech_1789114090821.mp3"
    }
  - 동작:
    ① 노트북 서버가 인물 이미지와 음성 파일을 데스크탑 ComfyUI로 자동 전송 (HTTP POST)
    ② 데스크탑 RTX 16GB GPU가 Wav2Lip으로 2~4초 만에 립싱크 렌더링
    ③ 완성된 MP4를 노트북의 `client/public/videos/` 폴더로 자동 다운로드
  - 응답:
    {
      "success": true,
      "figureId": "kim-koo",
      "videoUrl": "/videos/w2l_kim-koo_1789114117418.mp4",
      "engine": "ComfyUI Wav2Lip GAN (Remote RTX 16GB GPU)"
    }
  - 장점: 비디오 URL 수신 즉시 `<video>` 태그에서 립싱크 동영상이 매끄럽게 재생됨!


--------------------------------------------------------------------------------
 6. (선택 확장) 데스크탑 16GB VRAM을 활용한 LivePortrait 3D 모드
--------------------------------------------------------------------------------

만약 입술 립싱크뿐만 아니라 "눈 깜빡임, 고개 미세 회전, 풍부한 3D 표정"까지 원하신다면,
16GB VRAM에서는 `ComfyUI-LivePortraitKJ` 노드를 구동할 수 있습니다.

- 소요 시간: 4초 ~ 6초 (RTX 16GB 환경)
- 필요 커스텀 노드: custom_nodes/ComfyUI-LivePortraitKJ
- 동작 원리:
  * 원본 어진 이미지를 3D 표정 파라미터로 구동
  * 음성 볼륨/음소에 맞춰 입술과 머리가 자연스럽게 움직임
- 필요 시 언제든 동일한 3단계 파이프라인(audioUrl 전달)으로 전환 가능합니다.
